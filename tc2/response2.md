### Задача 1. Неравенство Чебышева
Длина изделия \( X \) — случайная величина с математическим ожиданием \( M[X] = 90 \) см и дисперсией \( D[X] = 0{,}0225 \). Требуется оценить вероятность того, что длина окажется в пределах от 89,7 см до 90,3 см.

Рассмотрим событие \( 89{,}7 < X < 90{,}3 \). Оно равносильно \( |X - 90| < 0{,}3 \). Положим \( \varepsilon = 0{,}3 \).

Согласно неравенству Чебышева (для любой случайной величины с конечной дисперсией):
\[
P\bigl(|X - M[X]| < \varepsilon\bigr) \ge 1 - \frac{D[X]}{\varepsilon^2}.
\]
Подставляем числовые значения: \( \varepsilon^2 = 0{,}09 \), \( D[X] = 0{,}0225 \). Тогда
\[
\frac{D[X]}{\varepsilon^2} = \frac{0{,}0225}{0{,}09} = 0{,}25.
\]
Следовательно,
\[
P(89{,}7 < X < 90{,}3) \ge 1 - 0{,}25 = 0{,}75.
\]
**Ответ:** \( \mathbf{P \ge 0{,}75} \).

### Задача 2. Двумерный дискретный случайный вектор

Совместное распределение дискретного случайного вектора \((X, Y)\) задано таблицей:

| \(X \setminus Y\) | \(1{,}3\) | \(2{,}5\) | \(3{,}2\) |
|----------------|---------|---------|---------|
| \(0{,}5\)        | \(0{,}2\) | \(0{,}2\) | \(0{,}1\) |
| \(1{,}5\)        | \(0{,}4\) | \(0{,}04\)| \(0{,}06\)|

Проверка: сумма всех вероятностей \(0{,}2+0{,}2+0{,}1+0{,}4+0{,}04+0{,}06 = 1\).

#### 2.1. Маргинальные законы распределения компонент \(X\) и \(Y\)

**Распределение \(X\)**  
\(P(X=0{,}5) = 0{,}2+0{,}2+0{,}1 = 0{,}5\);  
\(P(X=1{,}5) = 0{,}4+0{,}04+0{,}06 = 0{,}5\).

Таблица:

| \(x_i\) | \(0{,}5\) | \(1{,}5\) |
|--------|--------|--------|
| \(p_i\) | \(0{,}5\) | \(0{,}5\) |

**Распределение \(Y\)**  
\(P(Y=1{,}3) = 0{,}2+0{,}4 = 0{,}6\);  
\(P(Y=2{,}5) = 0{,}2+0{,}04 = 0{,}24\);  
\(P(Y=3{,}2) = 0{,}1+0{,}06 = 0{,}16\).

Таблица:

| \(y_j\) | \(1{,}3\) | \(2{,}5\) | \(3{,}2\) |
|--------|---------|---------|---------|
| \(p_j\) | \(0{,}6\) | \(0{,}24\) | \(0{,}16\) |

#### 2.2. Функции распределения \(F_X(x)\) и \(F_Y(y)\)

\(F_X(x) = P(X \le x)\) – кусочно-постоянная функция со скачками в точках \(0{,}5\) и \(1{,}5\):
\[
F_X(x) = \begin{cases}
0, & x < 0{,}5,\\
0{,}5, & 0{,}5 \le x < 1{,}5,\\
1, & x \ge 1{,}5.
\end{cases}
\]
График: горизонтальная прямая \(y=0\) левее \(0{,}5\); на \([0{,}5; 1{,}5)\) значение \(0{,}5\); правее \(1{,}5\) – \(1\). Скачки в точках \(0{,}5\) (величина \(0{,}5\)) и \(1{,}5\) (величина \(0{,}5\)).

\(F_Y(y) = P(Y \le y)\):
\[
F_Y(y) = \begin{cases}
0, & y < 1{,}3,\\
0{,}6, & 1{,}3 \le y < 2{,}5,\\
0{,}6 + 0{,}24 = 0{,}84, & 2{,}5 \le y < 3{,}2,\\
1, & y \ge 3{,}2.
\end{cases}
\]
График: ступенчатая функция; скачки в \(1{,}3\) (на \(0{,}6\)), в \(2{,}5\) (на \(0{,}24\)), в \(3{,}2\) (на \(0{,}16\)).

#### 2.3. Условные законы распределения

Условный закон \(X\) при условии \(Y = y_j\): \(P(X=x_i \mid Y=y_j) = \dfrac{P(X=x_i, Y=y_j)}{P(Y=y_j)}\).

- \(Y = 1{,}3 \;(P=0{,}6)\):  
\(P(X=0{,}5 \mid Y=1{,}3) = 0{,}2/0{,}6 = 1/3 \approx 0{,}3333\);  
\(P(X=1{,}5 \mid Y=1{,}3) = 0{,}4/0{,}6 = 2/3 \approx 0{,}6667\).

- \(Y = 2{,}5 \;(P=0{,}24)\):  
\(P(X=0{,}5 \mid Y=2{,}5) = 0{,}2/0{,}24 = 5/6 \approx 0{,}8333\);  
\(P(X=1{,}5 \mid Y=2{,}5) = 0{,}04/0{,}24 = 1/6 \approx 0{,}1667\).

- \(Y = 3{,}2 \;(P=0{,}16)\):  
\(P(X=0{,}5 \mid Y=3{,}2) = 0{,}1/0{,}16 = 5/8 = 0{,}6250\);  
\(P(X=1{,}5 \mid Y=3{,}2) = 0{,}06/0{,}16 = 3/8 = 0{,}3750\).

Условный закон \(Y\) при условии \(X = x_i\): \(P(Y=y_j \mid X=x_i) = \dfrac{P(X=x_i, Y=y_j)}{P(X=x_i)}\).

- \(X = 0{,}5 \;(P=0{,}5)\):  
\(P(Y=1{,}3 \mid X=0{,}5) = 0{,}2/0{,}5 = 0{,}4\);  
\(P(Y=2{,}5 \mid X=0{,}5) = 0{,}2/0{,}5 = 0{,}4\);  
\(P(Y=3{,}2 \mid X=0{,}5) = 0{,}1/0{,}5 = 0{,}2\).

- \(X = 1{,}5 \;(P=0{,}5)\):  
\(P(Y=1{,}3 \mid X=1{,}5) = 0{,}4/0{,}5 = 0{,}8\);  
\(P(Y=2{,}5 \mid X=1{,}5) = 0{,}04/0{,}5 = 0{,}08\);  
\(P(Y=3{,}2 \mid X=1{,}5) = 0{,}06/0{,}5 = 0{,}12\).

#### 2.4. Проверка независимости \(X\) и \(Y\)

Если \(X\) и \(Y\) независимы, то \(P(X=x_i, Y=y_j) = P(X=x_i)\,P(Y=y_j)\) для всех \(i,j\).  
Возьмём \(x_i=0{,}5,\; y_j=1{,}3\): совместная вероятность \(0{,}2\), а произведение маргинальных \(0{,}5 \times 0{,}6 = 0{,}3 \neq 0{,}2\).  
**Вывод:** случайные величины \(X\) и \(Y\) **зависимы**.

#### 2.5. Математические ожидания и дисперсии

\(M[X] = 0{,}5\cdot 0{,}5 + 1{,}5\cdot 0{,}5 = 0{,}25 + 0{,}75 = \mathbf{1{,}0}\).

\(M[Y] = 1{,}3\cdot 0{,}6 + 2{,}5\cdot 0{,}24 + 3{,}2\cdot 0{,}16 = 0{,}78 + 0{,}60 + 0{,}512 = \mathbf{1{,}892}\).

Для дисперсий найдём вторые начальные моменты.
\(M[X^2] = 0{,}5^2\cdot 0{,}5 + 1{,}5^2\cdot 0{,}5 = 0{,}125 + 1{,}125 = 1{,}25\).
\(D[X] = 1{,}25 - 1^2 = \mathbf{0{,}25}\).

\(M[Y^2] = 1{,}3^2\cdot 0{,}6 + 2{,}5^2\cdot 0{,}24 + 3{,}2^2\cdot 0{,}16 = 1{,}69\cdot 0{,}6 + 6{,}25\cdot 0{,}24 + 10{,}24\cdot 0{,}16 = 1{,}014 + 1{,}5 + 1{,}6384 = 4{,}1524\).
\(D[Y] = 4{,}1524 - 1{,}892^2 = 4{,}1524 - 3{,}579664 = \mathbf{0{,}572736}\).

#### 2.6. Корреляционный момент (ковариация) \(K_{XY}\)

\(K_{XY} = M[XY] - M[X]M[Y]\).

Вычислим \(M[XY] = \sum\sum x_i y_j p_{ij}\):
\[
\begin{aligned}
&0{,}5\cdot 1{,}3\cdot 0{,}2 = 0{,}13,\\
&0{,}5\cdot 2{,}5\cdot 0{,}2 = 0{,}25,\\
&0{,}5\cdot 3{,}2\cdot 0{,}1 = 0{,}16,\\
&1{,}5\cdot 1{,}3\cdot 0{,}4 = 0{,}78,\\
&1{,}5\cdot 2{,}5\cdot 0{,}04 = 0{,}15,\\
&1{,}5\cdot 3{,}2\cdot 0{,}06 = 0{,}288.
\end{aligned}
\]
Сумма: \(0{,}13+0{,}25=0{,}38\); \(+0{,}16=0{,}54\); \(+0{,}78=1{,}32\); \(+0{,}15=1{,}47\); \(+0{,}288=1{,}758\).
\(M[XY] = 1{,}758\).  
\(M[X]M[Y] = 1{,}0 \cdot 1{,}892 = 1{,}892\).  
\(K_{XY} = 1{,}758 - 1{,}892 = \mathbf{-0{,}134}\).

#### 2.7. Коэффициент корреляции \(r_{XY}\)

Средние квадратические отклонения: \(\sigma_X = \sqrt{0{,}25} = 0{,}5\); \(\sigma_Y = \sqrt{0{,}572736} \approx 0{,}7568\).

\(r_{XY} = \dfrac{K_{XY}}{\sigma_X \sigma_Y} = \dfrac{-0{,}134}{0{,}5 \times 0{,}7568} \approx \dfrac{-0{,}134}{0{,}3784} \approx \mathbf{-0{,}3541}\).

#### 2.8. Корреляционная матрица \(\Sigma\)

\[
\Sigma = \begin{pmatrix}
D[X] & K_{XY} \\
K_{XY} & D[Y]
\end{pmatrix}
= \begin{pmatrix}
0{,}25 & -0{,}134 \\
-0{,}134 & 0{,}572736
\end{pmatrix}.
\]

#### 2.9. Обобщённая дисперсия (определитель \(\Sigma\))

\(\det\Sigma = D[X]\,D[Y] - (K_{XY})^2 = 0{,}25 \times 0{,}572736 - (-0{,}134)^2 = 0{,}143184 - 0{,}017956 = \mathbf{0{,}125228}\).

#### 2.10. Условные математические ожидания (функции регрессии)

**Регрессия \(m_X(y) = M[X \mid Y=y]\)** – условное матожидание \(X\) при фиксированном \(Y=y\):

- \(y=1{,}3\): \(m_X = 0{,}5\cdot\frac{1}{3} + 1{,}5\cdot\frac{2}{3} = \frac{0{,}5+3}{3} = \frac{3{,}5}{3} \approx 1{,}1667\);
- \(y=2{,}5\): \(m_X = 0{,}5\cdot\frac{5}{6} + 1{,}5\cdot\frac{1}{6} = \frac{2{,}5+1{,}5}{6} = \frac{4}{6} \approx 0{,}6667\);
- \(y=3{,}2\): \(m_X = 0{,}5\cdot 0{,}625 + 1{,}5\cdot 0{,}375 = 0{,}3125 + 0{,}5625 = 0{,}875\).

График – ломаная с точками \((1{,}3;\; 1{,}1667)\), \((2{,}5;\; 0{,}6667)\), \((3{,}2;\; 0{,}875)\).

**Регрессия \(m_Y(x) = M[Y \mid X=x]\)**:

- \(x=0{,}5\): \(m_Y = 1{,}3\cdot 0{,}4 + 2{,}5\cdot 0{,}4 + 3{,}2\cdot 0{,}2 = 0{,}52 + 1{,}00 + 0{,}64 = 2{,}16\);
- \(x=1{,}5\): \(m_Y = 1{,}3\cdot 0{,}8 + 2{,}5\cdot 0{,}08 + 3{,}2\cdot 0{,}12 = 1{,}04 + 0{,}20 + 0{,}384 = 1{,}624\).

График – ломаная с точками \((0{,}5;\; 2{,}16)\) и \((1{,}5;\; 1{,}624)\); формально её можно описать как отрезок прямой между этими точками.

### Задача 3. Двумерный непрерывный случайный вектор (равномерное распределение)

Совместная плотность \(f(x,y)\) постоянна в области \(D\) и равна нулю вне её:
\[
f(x,y) = \begin{cases}
C, & (x,y) \in D,\\
0, & \text{иначе},
\end{cases}
\quad D = \{(x,y): x \ge 0,\; y \le 2 - x,\; y \ge x\}.
\]
Область \(D\) – треугольник. Пересечения:
\(y = x\) и \(y = 2-x\) дают \(x=1,\; y=1\).
Вершины: \((0,0)\) (из \(y=x\) при \(x=0\)), \((0,2)\) (из \(y=2-x\) при \(x=0\)) и \((1,1)\).  
Аналитически: \(x\) меняется от 0 до 1, при каждом \(x\) границы \(y\): \(x \le y \le 2-x\).

#### 3.1. Параметр \(C\)
Условие нормировки:
\[
\iint_D C\,dx\,dy = 1 \;\Longrightarrow\; C \cdot \text{Площадь}(D) = 1.
\]
Площадь \(D = \int_{0}^{1} ((2-x) - x)\,dx = \int_0^1 (2-2x)\,dx = \left[2x - x^2\right]_0^1 = 1\).
Следовательно, \(C = 1\). Совместная плотность:
\[
f(x,y) = \begin{cases}
1, & (x,y) \in D,\\
0, & \text{иначе}.
\end{cases}
\]

#### 3.2. Маргинальные плотности \(f_X(x)\) и \(f_Y(y)\)

**Плотность \(X\):**
\[
f_X(x) = \int_{y=x}^{2-x} 1\,dy = (2-x) - x = 2 - 2x, \quad x \in [0,1];
\]
\(f_X(x) = 0\) при \(x \notin [0,1]\).

**Плотность \(Y\):** область \(D\) по \(y\): от 0 до 2.
Для \(0 \le y \le 1\) допустимые \(x\): от 0 до \(y\) (так как \(x \le y\) и \(x \le 2-y\), при \(y \le 1\) имеем \(y \le 2-y\)).  
Для \(1 \le y \le 2\) допустимые \(x\): от 0 до \(2-y\).
\[
f_Y(y) = \begin{cases}
\displaystyle\int_{0}^{y} 1\,dx = y, & 0 \le y \le 1,\\[8pt]
\displaystyle\int_{0}^{2-y} 1\,dx = 2 - y, & 1 \le y \le 2,\\[4pt]
0, & \text{иначе}.
\end{cases}
\]

#### 3.3. Функции распределения \(F_X(x)\) и \(F_Y(y)\)

**\(F_X(x) = \int_{-\infty}^x f_X(t)\,dt\).**
- \(x < 0\): \(F_X = 0\);
- \(0 \le x \le 1\): \(F_X(x) = \int_0^x (2-2t)\,dt = \left[2t - t^2\right]_0^x = 2x - x^2\);
- \(x > 1\): \(F_X = 1\).

**\(F_Y(y) = \int_{-\infty}^y f_Y(t)\,dt\).**
- \(y < 0\): \(F_Y = 0\);
- \(0 \le y \le 1\): \(F_Y(y) = \int_0^y t\,dt = \frac{y^2}{2}\);
- \(1 \le y \le 2\): \(F_Y(y) = \int_0^1 t\,dt + \int_1^y (2-t)\,dt = \frac{1}{2} + \left[2t - \frac{t^2}{2}\right]_1^y\)  
  \(= \frac{1}{2} + \left(2y - \frac{y^2}{2} - 2 + \frac{1}{2}\right) = 2y - \frac{y^2}{2} - 1\);
- \(y > 2\): \(F_Y = 1\).

Проверка: \(F_Y(2) = 4 - 2 - 1 = 1\); \(F_Y(1) = 2 - 0{,}5 - 1 = 0{,}5\) совпадает с \(\frac{1^2}{2}\).

#### 3.4. Условные плотности

**\(f(x \mid Y=y) = \dfrac{f(x,y)}{f_Y(y)}\)** (при \(f_Y(y)>0\)):
- Если \(0 < y \le 1\): \(f_Y(y)=y\), \(f(x,y)=1\) для \(0 \le x \le y\).  
  \(f(x \mid Y=y) = \dfrac{1}{y},\; x \in [0,y]\), иначе 0.
- Если \(1 \le y < 2\): \(f_Y(y)=2-y\), \(f(x,y)=1\) для \(0 \le x \le 2-y\).  
  \(f(x \mid Y=y) = \dfrac{1}{2-y},\; x \in [0,2-y]\), иначе 0.

**\(f(y \mid X=x) = \dfrac{f(x,y)}{f_X(x)}\)** (при \(f_X(x)>0\)):
- Для \(x \in (0,1)\): \(f_X(x)=2-2x\), \(f(x,y)=1\) для \(x \le y \le 2-x\).  
  \(f(y \mid X=x) = \dfrac{1}{2-2x},\; y \in [x, 2-x]\), иначе 0.  
  Это равномерное распределение на отрезке \([x,\, 2-x]\).

#### 3.5. Проверка независимости
Сравним \(f(x,y) = 1\) на \(D\) с произведением \(f_X(x)f_Y(y)\).
Возьмём, например, \(x=0{,}2,\; y=0{,}5\): \(f_X(0{,}2)=2-0{,}4=1{,}6\), \(f_Y(0{,}5)=0{,}5\), произведение \(0{,}8 \neq 1\).  
Следовательно, \(X\) и \(Y\) **зависимы**.

#### 3.6. Числовые характеристики

**Математические ожидания:**
\[
M[X] = \int_0^1 x(2-2x)\,dx = 2\int_0^1 (x - x^2)\,dx = 2\left(\frac{1}{2} - \frac{1}{3}\right) = 2\cdot\frac{1}{6} = \frac{1}{3}.
\]
\[
M[Y] = \int_0^1 y\cdot y\,dy + \int_1^2 y(2-y)\,dy = \int_0^1 y^2\,dy + \int_1^2 (2y - y^2)\,dy.
\]
\(\int_0^1 y^2\,dy = \frac{1}{3}\).  
\(\int_1^2 (2y - y^2)\,dy = \left[y^2 - \frac{y^3}{3}\right]_1^2 = (4 - \frac{8}{3}) - (1 - \frac{1}{3}) = 3 - \frac{7}{3} = \frac{2}{3}\).  
\(M[Y] = \frac{1}{3} + \frac{2}{3} = 1\).

**Вторые начальные моменты:**
\[
M[X^2] = \int_0^1 x^2(2-2x)\,dx = 2\int_0^1 (x^2 - x^3)\,dx = 2\left(\frac{1}{3} - \frac{1}{4}\right) = 2\cdot\frac{1}{12} = \frac{1}{6}.
\]
\[
\begin{aligned}
M[Y^2] &= \int_0^1 y^3\,dy + \int_1^2 y^2(2-y)\,dy = \frac{1}{4} + \int_1^2 (2y^2 - y^3)\,dy \\
&= \frac{1}{4} + \left[\frac{2y^3}{3} - \frac{y^4}{4}\right]_1^2 = \frac{1}{4} + \left(\frac{16}{3} - 4 - \frac{2}{3} + \frac{1}{4}\right) \\
&= \frac{1}{4} + \frac{14}{3} - 4 + \frac{1}{4} = \frac{14}{3} - 4 + \frac{1}{2} = \frac{14}{3} - \frac{7}{2} = \frac{28 - 21}{6} = \frac{7}{6}.
\end{aligned}
\]

**Дисперсии:**
\(D[X] = \frac{1}{6} - \left(\frac{1}{3}\right)^2 = \frac{1}{6} - \frac{1}{9} = \frac{1}{18}\).  
\(D[Y] = \frac{7}{6} - 1^2 = \frac{1}{6}\).

**Корреляционный момент:**
\[
M[XY] = \iint_D xy\,dx\,dy = \int_0^1 x\left(\int_{y=x}^{2-x} y\,dy\right)dx = \int_0^1 x \cdot \frac{1}{2}\bigl((2-x)^2 - x^2\bigr)dx.
\]
\((2-x)^2 - x^2 = 4 - 4x\).  
Тогда \(M[XY] = \frac{1}{2}\int_0^1 x(4 - 4x)\,dx = 2\int_0^1 (x - x^2)\,dx = 2\cdot\frac{1}{6} = \frac{1}{3}\).  
\(M[X]M[Y] = \frac{1}{3} \cdot 1 = \frac{1}{3}\).  
\(K_{XY} = \frac{1}{3} - \frac{1}{3} = 0\).

**Коэффициент корреляции:** \(r_{XY} = 0\).

**Корреляционная матрица:**
\[
\Sigma = \begin{pmatrix}
D[X] & K_{XY} \\
K_{XY} & D[Y]
\end{pmatrix}
= \begin{pmatrix}
\frac{1}{18} & 0 \\
0 & \frac{1}{6}
\end{pmatrix}.
\]

**Обобщённая дисперсия:** \(\det\Sigma = \frac{1}{18}\cdot\frac{1}{6} - 0 = \frac{1}{108}\).

#### 3.7. Функции регрессии (условные математические ожидания)

**Регрессия \(X\) на \(Y\): \(m_X(y) = M[X \mid Y=y]\).**

- При \(0 \le y \le 1\): \(f(x \mid Y=y) = 1/y\) на \([0,y]\).  
  \(m_X(y) = \int_0^y x\cdot\frac{1}{y}\,dx = \frac{1}{y}\cdot\frac{y^2}{2} = \frac{y}{2}\).
- При \(1 \le y \le 2\): \(f(x \mid Y=y) = 1/(2-y)\) на \([0,\,2-y]\).  
  \(m_X(y) = \int_0^{2-y} x\cdot\frac{1}{2-y}\,dx = \frac{1}{2-y}\cdot\frac{(2-y)^2}{2} = \frac{2-y}{2}\).

График: ломаная линия, проходящая через точки \((0,0)\), \((1,\;0{,}5)\), \((2,0)\); состоит из двух отрезков: \(y/2\) при \(y \in [0,1]\) и \((2-y)/2\) при \(y \in [1,2]\).

**Регрессия \(Y\) на \(X\): \(m_Y(x) = M[Y \mid X=x]\).**

При \(x \in [0,1]\) условное распределение \(Y \mid X=x\) равномерное на отрезке \([x,\;2-x]\). Матожидание равномерного распределения есть середина отрезка:
\[
m_Y(x) = \frac{x + (2-x)}{2} = 1.
\]
График: прямая горизонтальная линия \(y=1\) при \(x \in [0,1]\).
